Unio - Privacy Policy

Ultimo aggiornamento: 22 novembre 2026

Last updated: November 22, 2026

In breve

Unio è progettata per funzionare senza account, senza tracciamento e senza pubblicità. Le tue preferenze, i tuoi impegni personali e le notifiche restano esclusivamente sul tuo dispositivo.

1. Dati salvati solo in locale

Tutti i dati legati all'utilizzo quotidiano dell'app vengono salvati esclusivamente in locale sul tuo dispositivo:

  • Preferenze di studio: anno accademico, corso di laurea, anno di corso, gruppo matricola (pari/dispari) e sede selezionata.
  • Impegni personali e notifiche: eventi personali creati dall'utente e promemoria locali programmati tramite iOS.
  • Cache locale: copia temporanea di orari, aule e coordinate per velocizzare il caricamento e consentire la consultazione offline.

Questi dati non vengono mai inviati a server esterni e vengono rimossi completamente utilizzando la funzione di reset nelle Impostazioni oppure disinstallando l'app.

2. Richieste al server per orari e avvisi

Per mostrare orari delle lezioni, disponibilità delle aule e avvisi di servizio, Unio effettua richieste HTTPS anonime al proprio server backend (unicalendar.dedyn.io). Le richieste includono uno User-Agent tecnico contenente versione dell'app, modello del dispositivo e versione del sistema operativo. Non vengono creati profili utente, né memorizzate cronologie personali delle richieste.

3. Invio volontario di Feedback

Solo se scegli esplicitamente di inviare una segnalazione dalla schermata Feedback nelle Impostazioni, l'app trasmette al server:

  • titolo e descrizione inseriti nel modulo;
  • eventuale immagine allegata (selezionata da te tramite il selettore di sistema di iOS);
  • informazioni tecniche del dispositivo (versione e build dell'app, modello del dispositivo, sistema operativo e relativa versione).

Al momento dell'invio, l'indirizzo IP viene utilizzato esclusivamente in memoria temporanea per prevenire abusi (rate limiting) e non viene salvato nel database. La segnalazione e l'eventuale allegato vengono conservati sul server e notificati privatamente allo sviluppatore tramite un bot Telegram dedicato al solo scopo di analizzare e risolvere il problema segnalato, e vengono eliminati una volta gestiti.

4. Servizi di sistema e di terze parti

  • Mappe e ricerca indirizzi (Apple Maps / MapKit): quando visualizzi la mappa di un'aula o cerchi un luogo per un impegno personale, le richieste vengono gestite direttamente da Apple secondo la Privacy Policy di Apple.
  • Calendario di sistema: l'aggiunta di una lezione al Calendario Apple avviene tramite il foglio nativo di sistema; Unio non legge né accede agli altri eventi del tuo calendario.
  • Libreria Foto: la scelta di uno screenshot per il feedback usa il selettore nativo di sistema; Unio riceve unicamente la singola immagine selezionata.
  • Nessun tracciamento: Unio non integra SDK pubblicitari, strumenti di analytics o sistemi di tracciamento di terze parti.

Summary

Unio is built to work with no user accounts, no tracking, and no ads. Your preferences, personal commitments, and reminders stay exclusively on your device.

1. Data Stored Locally Only

All data related to everyday use of the app is stored solely on your device:

  • Study preferences: academic year, degree course, course year, odd/even student ID group, and selected campus.
  • Personal commitments & notifications: custom personal events and local reminders scheduled via iOS.
  • Local cache: temporary copies of timetables, classrooms, and coordinates to improve loading speed and enable offline viewing.

This data is never transmitted to external servers and is completely deleted when you reset the app in Settings or uninstall it.

2. Server Requests for Schedules & Notices

To display class timetables, classroom availability, and service notices, Unio sends anonymous HTTPS requests to its backend server (unicalendar.dedyn.io). Requests include a standard technical User-Agent containing the app version, device model, and OS version. No user profiles or personal request histories are created or stored.

3. Voluntary Feedback Submissions

Only when you explicitly submit a report through the Feedback screen in Settings does the app send the following to the server:

  • the title and message you wrote;
  • an optional image attachment chosen by you via the system iOS photo picker;
  • technical device information (app version and build, device model, OS name and version).

During submission, your IP address is held temporarily in memory solely for anti-spam rate limiting and is not stored in the database. Submitted reports and optional attachments are stored on the server and forwarded privately to the developer via a dedicated Telegram bot solely to investigate and fix the reported issue, and are deleted once handled.

4. System & Third-Party Services

  • Maps & Location Search (Apple Maps / MapKit): when viewing a classroom map or searching for a location for a personal commitment, requests are handled directly by Apple under the Apple Privacy Policy.
  • Apple Calendar: exporting a class to Apple Calendar uses the native iOS sheet; Unio does not read or access your existing calendar events.
  • Photo Library: attaching a screenshot to a feedback report uses the native system picker; Unio only receives the single image you choose.
  • No tracking: Unio does not include advertising SDKs, analytics libraries, or third-party tracking tools.

5. Contact

Unio is developed by Leonardo Rossi. If you have any privacy questions or wish to request deletion of a submitted feedback report, please contact leonardo.rossi1922005@gmail.com.
